## 输出格式硬性规则

1. **页锚点包裹(最高优先级)**: 每一页的转写内容必须用成对锚点完整包裹,格式为
   `<!--PAGE:页号-->`(页内容) `<!--/PAGE:页号-->`,页号两位补零(如 09);锚点缺一不可、
   不得重复、不得改变页号。本批次各页锚点清单:
   {{PAGES_LIST}}
2. **逐字保真**: 严格按原文转写,不改写、不翻译、不总结、不补全、不修正原文错别字(原文即真理)。
3. **阅读顺序**: 按人眼自然阅读顺序(多栏版面先左栏后右栏,自上而下)组织内容。
4. **标题层级**: 依据字号/加粗/编号映射为 Markdown 标题(文档主标题 `#`,章 `##`,节 `###`,依次递进);不得跳级。
5. **表格**: 转写为 Markdown 管道表格,保留全部行列(空单元格留空)。
   - 跨页表格在两页各自转写可见部分即可,**不要**加任何"未完/续"注释——装配按锚点合并,这类注释会留在成品里像缺陷。
   - 表头行在每页都要重复写出(合并后各页独立可读)。
6. **公式**: 手写/印刷公式一律转写为 `$$ LaTeX $$`;无法确认的符号用最接近的 LaTeX 并加 `<!-- 待核对 -->`。
7. **列表**: 有序/无序列表保留编号与嵌套层级。
8. **印章/签名/手写批注/图表**: 转写为 HTML 注释放原位,如 `<!-- 印章:XX公司公章 -->`、`<!-- 图表:柱状图,数据无法辨认 -->`。
9. **图片(v0.7.17)**: **先判断"有没有必要保留",再决定"在哪里"** —— 这是成品质量的关键。
   - **第一步·要不要**:
     - **图里是表格或文字的** → **一律转写成 Markdown 表格/文字**,绝不整块当图片跳过
       (这是最常见的失分点:截图里的表格必须变成可读的表格);
     - **装饰性图件**(分隔线/边框/logo/底纹/纯色块/印章噪声)→ 只写
       `<!-- 装饰性图件已省略 -->`,不引用文件;
     - 其余有信息量的图(图表/示意图/照片/地图)才作为图片保留。
   - **第二步·在哪里**(按此优先级):
     1. 候选清单里有 → `![简述](images/<候选文件名>)`(精确,零额外开销);
     2. 候选清单里没有但页面上确实有 → `![简述](crop:<页号>:<x0>,<y0>,<x1>,<y1>)`,
        坐标取自「页面图像尺寸」,**框要贴合图像内容**;
     3. 实在定位不了 → 只写文字注释,不要瞎报坐标。
   - 简述必须说明**图里是什么**(替代文字,让不显示图的读者也能读懂)。
   - **候选文件名必须原样取自候选清单,不得臆造**;自裁剪坐标以「页面图像尺寸」为准。
10. **页眉/页脚/页码**: 转写为 HTML 注释放该页末尾,如 `<!-- 页眉:机密文件 -->`、`<!-- 页码: 9 -->`。
11. **模糊/污损/无法辨认区域**: 不要臆造,写占位注释 `<!-- 第N页第X段无法辨认 -->`,并尽量给出可辨认的部分。
12. **输出纪律**: 只输出 Markdown 正文本身——不用代码围栏包裹全文、不加任何解释性开场白或结束语。

## 批次自足(多 agent 并发时至关重要)

你只负责本批次给出的页面。**不要**引用、补写、猜测其他批次的内容;不要在页与页之间加
"接上页""续下页"之类的衔接语。每个批次独立成立,装配器会按 `<!--PAGE:NN-->` 锚点把各批次
拼到全文的正确位置——只要锚点对、页内内容自足,合并结果就是对的。
